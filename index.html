BillPay-POS

iPad point-of-sale for healthcare clinics

70 cards, Figma to TestFlight, entirely mine. Card-present payments through the AnyPay SDK and a Chipper 3X Bluetooth reader, manual payments through the MXMerchant API — and per-clinic credentials isolated in Google Secret Manager so one tenant can never spend another's.

  • Resolved Swift 6 strict concurrency and actor isolation across the codebase
  • Firestore rules scoped so a clinic only ever reaches its own patients
  • Removed the auth token from manual-payment requests — real attack surface, gone

About

how i got here

I graduated in Computer Science from Khulna University of Engineering & Technology and went almost straight into being the only developer on a healthcare payments app. That turned out to be the fastest way to learn: when nobody else is going to catch it, you read the SDK docs properly, you write the logging, you learn what a Firestore security rule actually allows.

Eleven months later I'd shipped three apps and spent a stretch as the QA automation engineer on Lab3's core platform — which, honestly, made me a better app developer than any amount of feature work would have. Chasing why a test suite lies to you teaches you to distrust the happy path.

Outside code I was General Secretary of the CSE Association at KUET, running operations for 500+ students. I play table tennis badly and write about what I'm learning.
